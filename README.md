# InsideBCG Portal Enhancement 🚀

A modernized internal portal designed and developed for Boston Consulting Group (BCG) to improve employee productivity, collaboration, and accessibility through a responsive and feature-rich user interface.

## 🌟 Overview

InsideBCG is BCG’s internal web portal used globally by consultants and staff to access tools, content, and organizational updates. My work focused on revamping the homepage and enhancing utility through key features that improve daily workflows and stakeholder communication.

## 💼 My Role

As a **Junior Specialist** at BCG, I contributed to the **design, development, and backend integration** of new features in the InsideBCG portal. My work included UI/UX enhancements, API integrations, and creating a scalable backend to support dynamic content and user personalization.

---

## 🛠️ Tech Stack

### 💻 Frontend
- **Next.js** – For server-side rendering and fast, optimized React pages.
- **React.js** – Component-based frontend development.
- **Tailwind CSS** – Utility-first CSS framework for responsive design.

### 🔧 Backend
- **Node.js & Express.js** – REST API backend for handling requests and services.
- **PostgreSQL** – Relational database to store user data and preferences.

### 🧩 Integrations
- **Outlook Calendar API** – For scheduling events and meeting sync.
- **Slack API** – To enable contextual communication directly from the portal.

---

## 🖼️ Features Delivered

- **Dynamic Calendar Widget** – Shows meetings/events from integrated Outlook accounts.
- **Recently Visited Section** – Smart cache of pages recently accessed by the user.
- **Location-Based News Feed** – Tailors content based on the user’s BCG office location.
- **Toolbox** – Quick access to most-used internal productivity tools.
- **Fully Responsive UI** – Mobile-first layout using Tailwind CSS for consistency across devices.
- **Dark Mode (Prototype)** – Initial toggle switch for improved accessibility.

---

## 🎯 Purpose & Impact

The upgraded InsideBCG portal aimed to:
- Increase employee efficiency by centralizing access to tools, calendar events, and updates.
- Provide a personalized experience based on user behavior and location.
- Improve visual and performance aspects of the portal using modern web technologies.

Post-launch, the redesigned portal recorded:
- 📈 **~30% boost in average session duration**
- 💬 **Higher satisfaction ratings from internal stakeholders**
- 🔁 **Improved tool discoverability and navigation flow**
